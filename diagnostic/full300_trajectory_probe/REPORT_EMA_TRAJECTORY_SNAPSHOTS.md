## 9. W/h 分解（核心）

对称分解，**恒等式精确成立**（`rep_sym + cls_sym + Δb == Δlogit`，两角色误差 0.000）：

```
rep_sym = [(T2−T1) + (T4−T3)] / 2      （用旧 W 与用新 W 读表征，取平均）
cls_sym = [(T3−T1) + (T4−T2)] / 2      （用旧 h 与用新 h 读分类器，取平均）
```

### 5.1 分组各自（0-based 0 → 290）

| 角色 | rep_sym | cls_sym | Δb | Δlogit |
|---|---:|---:|---:|---:|
| **G86** | **−2.563** | **−7.063** | −0.113 | −9.739 |
| **CONTROL** | **+5.394** | **−2.507** | −0.006 | **+2.881** |

### 5.2 两个问题，两个不同答案 ⚠️

**① 问「G86 logit 水平为何下降」**（−9.739）：

```
rep −2.563  +  cls −7.063  +  Δb −0.113
⇒ 分类器侧 2.8× 主导
```

**② 问「G86 为何与 CONTROL 分离」= collapse 的定义**（−12.620）：

```
rep −7.957 (63%)  +  cls −4.556 (36%)  +  Δb −0.107
⇒ 表征侧 1.7× 主导
```

**为什么不同**：分类器漂移是**全局向下压**的（G86 −7.06，CONTROL 也 −2.51），所以它解释的是
"logit 整体下沉"，而不是"两组分开"。表征漂移则是**分组歧视性**的（G86 −2.56 vs CONTROL **+5.39**）。

### 5.3 自动判定 `CASE B` 为何是错的

`_analyze300.py` 的 §18 只用 `|T3−T1| = 4.718`（分类器）对 `|T2−T1| = 0.900`（表征），
**基准点写死在 epoch 0** —— 用旧方向 W₀ 去读已大幅漂移的 h_t，会**系统性压低表征侧**。
换成对称分解后：

```
按 ①（水平）：rep 2.563 / cls 7.063 —— 两侧均 ≥ MATERIAL_NATS=2.0
按 ②（分离）：rep 7.957 / cls 4.556 —— 两侧均 ≥ 2.0
```

**⇒ CASE C（coupled），不是 B。** 两侧都过 material 线，只是相对大小取决于问的是水平还是分离。
