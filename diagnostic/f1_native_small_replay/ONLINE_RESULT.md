## 3. 幅度校准：×85.9 换算规则出现**首个族内偏离点**

| 模型 | fork(best) | 线上 | 线上/fork | best − last |
|---|---:|---:|---:|---:|
| D′（sepstem + CLAHE） | 0.56690 | 48.712 | **85.93** | 0.01168 |
| OASA 1.4 | 0.56070 | 48.134 | **85.85** | 0.01275 |
| OASA 2.0 | 0.55409 | 47.610 | **85.92** | 0.00972 |
| **F1（+ native-small replay）** | **0.56485** | **48.204** | **85.34** | **0.01903** |

```text
族内前 3 点比值 85.85–85.93（散布 0.09%）
F1 比值 85.34  ⇒  偏离族心 85.90 **−0.65%**（约族内散布的 7 倍）
用族心换算 F1 应得 48.520，实测 48.204  ⇒  高估 **+0.316**
```

### 3.1 一个待验证的解释：**曲线尖峰**

`best − last` 是「best.pt 有多像孤峰」的粗指标：

```text
族内三个校准点：0.00972 / 0.01168 / 0.01275      ← 全部平坦，比值全在 85.85–85.93
F1            ：**0.01903**                       ← 唯一明显更尖的，也是唯一偏离比值的
```

⇒ **假设 H-spike**：`线上 ≈ fork(best) × 85.9` 这个换算在**曲线平坦**时成立；
当 `best − last` 明显超过族内常态（本例 ~0.013）时，**best.pt 是孤峰，该换算高估线上**。

**⚠ 证据强度：n=1 的偏离点，只是假设，不是规则。** 支持与反对：

- 支持：F1 同时是「最尖的曲线」与「唯一偏离比值的点」，两件事同时出现不是必然；
  且 F1 的 `best−last` 是族内最大值的 **1.5×**，超出幅度足够大。
- 反对：只有 1 个数据点；且 F1 同时**改了配方**（加了 replay 变换），
  偏离也可能来自「新配方使 ×85.9 本身漂移」——这正是 memory 里已写明的 caveat
  （"首次用新配方时不要把换算当精确预测"）。**两种解释目前不可区分。**

**可操作的下界交叉核对**（无论哪种解释都成立）：

```text
用 fork(last) 换算：D′ 0.55522 vs F1 0.54582 ⇒ Δ = −0.00940 × 85.9 = **−0.807**
用 fork(best) 换算：Δ = −0.00205 × 85.9 = **−0.176**
实测：                **−0.508**   （落在两者之间，更靠近 last 那一端）
```

⇒ **今后提交前应同时看 fork(best) 与 fork(last) 两个换算，用它们的区间当预测带**，
而不是只信 best 那个点。F1 的实际结果落在该区间内。

## 4. 本地机制读数与线上结果一致（事后印证）

上一轮 `RESULT.md` 已记录，现在看它们**都指向线上为负**：

| 本地读数 | 值 | 与线上 −0.508 的关系 |
|---|---|---|
| 官方 mAP50-95 Δ | +0.00336（**符号错**） | 无预测力 |
| 配对 bootstrap | **CI [−0.0071, +0.0182] 含 0，P(Δ>0)=0.78** | 当时即"与噪声不可区分" |
| **尺度分解** | small **+0.0068** / medium −0.0024 / **large −0.0040** | 净额本身就是回吐型 |
| **small 检出率** | **+1/371**（223→224）；large **+21** | 目标机制**没有兑现** |
| **IoU 分解** | 0.50–0.85 全正，**0.95 −0.0395** | 严定位段大幅回吐 |
| min_conf 稳健性 | Δ 在 conf≥0.05 后归零 | 增益只在低置信尾部 |
| G1（38 条） | 38/38 零重叠 → **33/38**（仅 2 检出） | 硬样本几乎没被撬动 |

⇒ **最该被当回事的一条**：**预注册的机制（small exposure → small 受益）在本地就只在 mAP 上"看起来"兑现
（small +0.0068），而在最直接的检出率指标上没有兑现（+1 个目标）**。
如果当时把「small 检出率」当作机制是否成立的判据（而不是把 small mAP 当判据），
本轮的提交决定会不一样。
