# rect vs square A/B 报告（阶段四/五）

- **日期**：2026-09-15
- **模型**：F4 = YOLO11m RGBD Mid-Fusion @1280（`runs/urban_multimodal_det_yolo11_rgbd_f4_1280/weights/best.pt`）
- **对比对象**：`predict_rect.py --mode rect`（修复）vs `--mode square`（复刻原 predict.py）
- **唯一变量**：rect 矩形 letterbox（736×1312）+ 显式 ratio_pad vs square 1280×1280 + 无 ratio_pad

---

## 1. 严格 A/B（val 集，fork 指标，conf=0.001/iou=0.7/max_det=300/max_boxes=300）

| 指标 | rect（修复） | square（原 pipeline） | Δ |
|---|---|---|---|
| mAP50-95 | **0.53264** | 0.51835 | **+0.01429** |
| mAP50 | 0.77863 | 0.76720 | +0.01143 |
| mAP75 | 0.58069 | 0.56000 | +0.02069 |
| Precision | 0.83948 | 0.83657 | +0.00291 |
| Recall | 0.72090 | 0.70990 | +0.01100 |
| 预测实例（总框数） | **5152** | 6955 | −1803 |

## 2. 关键结论

1. **rect 复现 model.val()**：mAP50-95 = 0.53264 ≈ 训练内置 val 0.53273（Δ=0.00009），预测框数 5152 与 val save_txt **完全一致**（394/394 框数一致，坐标到 1e-6）。
2. **rect 比 square 高 +0.01429**：与审计预测的 −0.0141 一致，即「square 相对 val 损失 −0.0141」被 rect 修复完全回收。
3. **机制**：square 的 1280×1280 画布（上下各 280px 填充）让特征图对齐偏移，导致**过检**（+1803 框）；rect 的 736×1312 画布（上下 8px/左右 16px 填充）与 val 完全一致，框数与置信度对齐。
4. **Recall 与 Precision 双升**：rect 不仅少框（P↑），Recall 也更高（R↑0.011），说明不是靠牺牲召回换精度，而是特征对齐更好。
