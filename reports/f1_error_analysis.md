# F1 误差与数据诊断报告

> 基线：F1 = YOLO11m RGBD 中期融合，imgsz=1024，batch=8，SGD lr0=0.005，best mAP@0.5:0.95 = **0.51955**（ep287）。
> 本报告基于 F1 `best.pt` 在验证集（400 图，其中 2 图因标签越界被忽略 → 398 图 / 2807 GT）上的评估，
> 与 `data/processed/depth_split_train` 的数据/标签审计。

---

## 0. 摘要（结论先行）

1. **数据对齐基本健康**：RGB/Depth 严格一一对应、尺寸一致、几何变换一致、无缺失重复、无真实近重复泄漏。
2. **主要瓶颈 = 小目标召回不足 + person 类主导**：整体 `P=0.867 / R=0.679`，**漏检（R 低）远大于误检（P 高）**。
   小目标密集类别（sign/bicycle/ball/person）召回率仅 0.49~0.65，且 AP50→AP75 大幅下滑（定位也差）。
3. **误差是「目标 vs 背景」，不是「A 类 vs B 类」**：混淆矩阵中跨类误判仅 20 例（0.70% of GT）。
   任何以提高类间判别力为假设的方案都不会有收益；增益只能来自「定位到更多目标」。
4. **person 占全部 GT 的 37.2%（1045 实例），AP 仅 0.464** —— 这是单点最高杠杆。
5. **次要问题**：depth 约 31.5% 像素无有效深度信号；8-bit JPG depth（7.5%）跳过归一化与 16-bit PNG 尺度不一致。
6. 实验证据：规模（s→m +0.024）、分辨率（768→1024 +0.020）均敏感；P2 头（E5）与 close_mosaic（E7m0）已证伪。

### 额外发现

- **8-bit JPG depth 归一化不一致**：149/2000（7.5%）depth 是 8-bit JPG，代码 `if dtype != uint8` 使其**跳过** `<300→0, /19999*255` 归一化，直接当灰度用。它与 16-bit PNG depth 的数值尺度未必一致，是潜在的小噪声源。
- **两档分辨率混存**（1920×1080 与 640×360）：640×360 图 resize 到 1024 时是 2.67× 上采样，小目标信息已不可逆丢失——但这批只有 149 张，影响有限。

### 重点类别解读

- **person（37.2% 全部 GT，最高杠杆）**：AP 仅 0.464，R=0.646（**35% 的行人漏检**），AP50→AP75 掉 0.304（定位差）。32% 是小目标（远距离行人）。**person 每 +0.05 AP ≈ 整体 mAP +0.019**，是最值得投入的单一类别。
- **sign / bicycle / ball：典型小目标漏检**。三者 R 只有 0.49~0.55（近半漏检），中位面积 898~1944px²（在 1024 下 <2% 边长），小目标比 30~58%。AP75 均 <0.42，定位严重不足。
- **light（P=0.785 全场最低）**：误检偏多。混淆矩阵显示其 56 个误检**几乎全部是背景误检（FP=56 / GT 244）**，
  没有任何一类被系统性误判成 light（跨类误判仅 4 例来自 sign）。即 light 的问题是「把不是 light 的东西当 light」，不是「分不清 light 与某类」。
- **boat**：样本仅 28，P/R 双低（0.799/0.567），统计波动大，不宜单独优化。
- **uav / seat / tricycle**：样本少或大目标，AP 已较高，不是瓶颈。

**三个决定性结论：**

1. **跨类误判几乎为零：全场仅 20 例（占 GT 0.70%）**。唯一略成对的只有 sign↔light（light→sign 4 例），
   这是两类小尺寸发光/标识目标，属可忽略量级。**「模型分不清两类」不是问题**——任何以「更好的分类头 / 跨模态判别力」为假设的实验都不会有收益。
2. **全部误差集中在「目标 vs 背景」**：漏检 734 例、误检 490 例，合计 1224 例，是跨类误判的 61 倍。
   这是纯粹的**召回/定位问题**，不是分类问题。
3. **困难类的漏检是「硬漏检」**：在 conf=0.001（几乎所有框都算）且 IoU 阈值放宽到 0.45 的条件下，
   sign 检测率仍只有 60.0%、bicycle 56.0%、ball 52.6% —— 意味着这些目标**从未被定位到**（不是置信度不够被阈值砍掉，
   而是根本没有产生足够 IoU 的框）。person 74.1% 的检测率也说明其中约 10pp 的 GT 只在极低置信度下才命中。
   **这是小目标分辨率/特征不足的直接证据，指向输入分辨率与特征图尺度，而非后处理。**

## 三、定位问题分析

| 指标 | 值 | 解读 |
| :--- | :---: | :--- |
| AP50 | 0.769 | 粗定位尚可 |
| AP75 | 0.561 | **较 AP50 掉 0.208**，精定位不足 |
| AP50-95 | 0.519 | 受精定位拖累 |
| Precision | 0.867 | 误检少 |
| Recall | 0.679 | **漏检是主矛盾（32% 目标被漏）** |

**定位问题集中在小目标**：
- 大目标 gap 小：seat 0.829→0.773（gap 0.056）、car 0.802→0.581（0.221）；
- 小目标 gap 巨大：ball 0.652→**0.315**（gap 0.337）、person 0.769→0.465（0.304）、sign 0.641→0.404（0.237）。

**判断（六选一）**：当前主要问题最接近 **「4. 小目标分辨率不足」+「2. 召回不足」的组合**，而非分类错误（P 高）、或纯定位不准（大目标定位很好）、或 depth 无效干扰（次要）。即：模型「看得见大的、看不见小的」，小目标要么漏、要么定位粗。RGBD 融合本身已发挥作用（depth 已带来 +0.027 增益），不是瓶颈。

---

## 四、主要瓶颈结论

1. **小目标召回不足（第一瓶颈）**：sign/bicycle/ball/person 的小目标漏检率 35~51%，根因是 8× 下采样后 <32px 目标在 P3 特征图上只剩 ~4px，信息不足。
   **混淆矩阵佐证**：这些类在 conf=0.001、IoU=0.45 的极宽松条件下检测率仍只有 52.6~60.0%，说明是**硬漏检**（没框出来），阈值/后处理无法挽救。
2. **误差 100% 是前景/背景二分类失败，而非类间混淆**：跨类误判 0.70%。因此**不要**在分类头、类间判别、跨模态注意力方向上投入。
3. **person 主导**：占 37% GT、AP 0.464，是单一最高杠杆类别。其检测率 74.1% → mAP 口径 R 0.646，差额来自低置信度框，属置信度标定问题（训练侧），非阈值问题。
4. **模型容量/分辨率敏感**：历史实验 s→m（+0.024）、768→1024（+0.020）均显著正向，当前 YOLO11m@1024 仍有向上空间。
5. **次要**：depth 31.5% 无效像素 + 8-bit JPG 尺度不一致，是模态质量噪音，非主瓶颈；但 0 值语义歧义（有效近距离 vs 无效）值得用一个掩码通道显式区分。
