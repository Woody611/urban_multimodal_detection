## 4. 第三阶段：推理侧实验判定

### 4.1 决定性证据：现有框集合的 TP 已是上限

错误分析中的贪心匹配**使用了全部 4824 个预测框，未按 confidence 过滤**。

- 在现有框集合下，**TP = 2288 已是最大值**；
- 剩余 **FN = 519 在现有框集合下不可约**（其中 358 个是纯漏检，连一个重叠框都没有）；
- 因此 **任何纯后处理（重排序、阈值过滤、置信度重标定）都无法新增任何真阳性**，
  只能改变 PR 曲线的形状。

**这条结论直接排除了所有「不重新推理」的后处理方案。**

### 4.2 需要重新推理的杠杆 —— 逐个检查

## 5. 第四阶段：训练授权评估

**本阶段结论：暂不申请训练授权。** 理由如下。

### 5.1 错误分析指出的唯一结构性问题

漏检率随尺度单调恶化：**小目标 36.9% vs 中目标 13.6% vs 大目标 5.3%**。
person 是最大单一贡献者（占 GT 37.2%、FN 38.2%、FP 48.3%），且其 FN 目标面积中位数
（1316px）仅为 TP（6903px）的 1/5。

### 5.2 但对应杠杆已被历史实验消耗或证伪

| 杠杆 | 历史实验 | 结果 |
|---|---|---|
| **输入分辨率** | 640 (E4) → 768 (E6) → 1024 (E7/F1) → **1280 (F4)** | 逐级有效；1024→1280 = **+0.01318**。**1536 未测**，但成本高、收益不确定 |
| **模型容量** | YOLO11m → **YOLO11l @1280 (F5)** | **证伪**：0.52619 < F4 0.53273（−0.0065），mAP75 下降 |
| **P2 检测层** | E3（s 规模）、E5（m 规模） | **两次独立证伪**：E3 −0.07459；E5 仅 +0.00013 |
| **学习率** | E7 (0.01) → F1 (0.005) | 已优化（+0.01077） |
| **close_mosaic** | close_mosaic=0 vs 10 | 已证伪，best 不变 |
| **融合方案 + 模态** | F4 RGBD mid → **RGBID early (5ch)** | 已兑现（+0.02527 本地 / +0.02129 线上） |
