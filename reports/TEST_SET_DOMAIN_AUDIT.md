## 0. 结论先行

```text
TEST_SET_DOMAIN_AUDIT = NO_MEANINGFUL_DOMAIN_SHIFT_FOR_TTA
值得做部分 TTA 吗？   = NO
推荐的单变量 TTA 实验数 = 0
```

三条硬证据：

1. **在任一「分辨率 × 格式」分层内部，test 与 train 的 RGB / IR / Depth 分布几乎逐项相同。**
   大样本分层（n = 883 vs 1851）上的最大标准化的组间差异：
   visible **|d| ≤ 0.077**、depth **|d| ≤ 0.118**、infrared **|d| ≤ 0.258**（且方向不一致、非对比度/动态范围类量）。
   中位/高端分位数几乎逐点重合。
2. **宽高比 / padding 偏移恰好为 0**：全部 13 200 张图**无一例外**是 16:9，
   经 rect letterbox 后画布恒为 **1280×736**、padding 恒为 **2.174%**。
   唯一「零成本、通常安全」的 TTA 家族在这里**没有任何可校正的对象**。
3. **真正的差异是「构成差异」（mixture shift），不是「分布差异」（distribution shift）**。
   TTA 是逐图变换，**无法作用于数据集构成**；而唯一的可观测代理量（分辨率）
   其 TTA 响应实测为**负**（族 N 的 LR 子集 multiscale Δ = −0.005 / −0.010）。

另有三条新发现，均**削弱**而非支持 TTA：

- 现有 multiscale TTA 的正增益**集中在测试集占比最小的族**上；把 val 的族构成重加权到 test 构成，
  其增益被侵蚀 60–75%。
- **测试集 14.5% 的图与 train/val 存在 >0.99 近邻**（8.0% 在 >0.999），
  其中 **LR 子集高达 96.6%**，且 55.5% 是 |Δ帧| ≤ 3 的**视频相邻帧**（79.7% ≤ 10 帧）—— 划分切在序列内部。
- 仓库中**不存在**「完整 TTA 线上提交」的任何记录（见 §5.1，需你确认口径）。

## 3. Domain-shift 分析（逐条回答 A–E）

### A. Resolution shift —— **存在，但是「构成」而非「分布」**

| 量 | test | test_pre | train_raw | split_val |
|---|---:|---:|---:|---:|
| LR(640×360) 占比 | **11.7%** | 15.5% | 7.45% | 6.75% |
| test/train 比值 | **1.57×** | 2.08× | — | — |
| **族 N 内部**的 LR 占比 | **16.03%** | 25.0% | 14.16% | 12.50% |

LR 只出现在命名族 `N` 内部（**其他族 100% 是 HR**，见 §3.6）。
在族 N 内部，LR 占比 train 14.16% vs test 16.03% —— **相差 1.9pp，基本稳定**。
→ 测试集「更低分辨率」这一观感，**几乎全部来自族构成变化**，而非分辨率本身漂移。

### B. RGB shift —— **无**

HR 层（n=883 vs 1851）：亮度 mean 差 **+0.018/255**、对比 std 差 **−0.29**、饱和像素差 +0.17pp。
全部指标 |d| ≤ 0.077。LR 层最大 |d| = 0.379（p1），样本量 117/149，多重比较后不显著。
→ **不存在更暗/更亮/曝光分布变化。**

### C. IR shift —— **无**

HR 层 |d| ≤ 0.258；中位/高端几乎相同；仅低端 p1/p5 略暗（4.14 vs 5.65）。
且管线对 IR 做**逐图 1%/99% 分位拉伸**（`base.py:337`）或 CLAHE —— 低端的这点差异
在进入网络前已被逐图归一化吸收。→ **无 contrast / dynamic-range 分布偏移。**

### D. Depth shift —— **无**

invalid 比例 +1.9pp（d = 0.096），深度中位 5079 vs 5089 mm（差 0.2%），
p99 16839 vs 16456 mm（+2.3%）。→ **无 invalid-ratio / dynamic-range 偏移。**

### E. Aspect-ratio / padding shift —— **恰好为 0（构造性）**

- 全部 4 个集合、3 个模态、13 200 张图：宽高比**只有 16:9 一个取值**。
- rect letterbox 后画布**恒为 1280×736**，padding **恒为 2.174%**（= 736×1280 画布中 16px 对齐余量）。
- 缩放比只有 {0.6667, 2.0} 两个取值（HR 缩小 / LR 放大 2×）。
→ 现有 inference LetterBox **不存在任何 padding 比例变化**。
**「针对 padding 的 TTA」在本数据集上没有任何可校正对象。**

### 3.6 命名族构成（本次审计新发现的偏移维度）

| 族 | test | test_pre | train_raw | split_val | **test/train** |

## 5. 现有完整 TTA 为什么无效 —— 诊断

### 5.1 仓库记录与本轮前提的出入（须你确认）

用户前提是「完整 TTA 在线上没有带来收益」。**本仓库中不存在任何 TTA 线上提交的记录**：

- `reports/final_competition_freeze_audit.md:26,130` 明确写「TTA ❌ **不提交**」；
  第 136 行把「新 TTA」列入**未执行**清单。
- 全部线上分数记录（0.53180 / 0.51051 / 0.50451 / 47.985 / 48.712）**均无 TTA 版本**。
- `diagnostic/final_sprint/rgbid_online_score_analysis.md:89-115` 只有**计划**（「方案 B（TTA）→ 首选」）。

→ 本报告的 §5 只能基于**本地 400 图 val 的既有落盘预测**做诊断；
「线上无收益」作为你方前提接受，但**其证据不在仓库内**。

### 5.2 实现与融合方式（读取既有产物，未重跑）

| 项 | HFlip | MultiScale |
|---|---|---|
| 分支 | 原图 + 水平翻转（5ch 整体翻转） | imgsz **1024 / 1280 / 1536**（= 0.8×/1.0×/1.2×） |
| 融合 | `_nms_merge`：**逐类 NMS（IoU 0.7，按 conf 贪心）** | 同左 |
| 分数融合 | **无**（无平均、无 WBF、无 box voting） | **无** |
| **各分支独立结果是否保留** | **否** —— `inference_audit.py` 的 `all_dets` 用完即弃，只写合并后 TXT | **否** |

规模（官方口径，400 图）：baseline 0.50928 → HFlip **0.50291**（−0.00637）→ MultiScale **0.51360**（+0.00432）；
fork 口径：baseline 0.55743 → 0.54040 / 0.54299（**均 −0.014~−0.017**）。

### 5.3 失败原因诊断：**不是「fusion 稀释」，有三个各自独立的真实原因**

**① hflip 是结构性无效分支。**
训练配置未覆盖 ultralytics 默认 `fliplr: 0.5`（`ultralytics/cfg/default.yaml:114`）。
模型**已被显式训练为翻转不变** → 翻转分支不提供任何新信息，只多出一组框参与 conf 竞争。
实测代价正好落在定位上：mAP**75** 从 0.62455 崩到 0.56887（**−0.0557**），
而 mAP50 反而 +0.0009。这正是「conf 更高的框赢、但它定位更差」的签名。

**② multiscale 的收益全部来自大目标，小目标收益实测为零。**
既有分桶结果：small AP50-95 −0.00025（≈0），large **+0.0162**；
同时退化框（w/h ≤ 0）65 → **188（2.9×）**，含退化框文件 7.5% → 12.3%。
且**单尺度 1536 已单独实测为负**（官方 0.50398 vs 0.50928 = **−0.00530**）。

**③ 「fusion 稀释单一有效分支」这一解释不成立 —— 融合是「按 conf 择优」而非「平均」。**
逐类 NMS 按 conf 保留每个目标分数最高的框，等价于 best-of-N 选择，
一个无效分支只有在**它的 conf 更高**时才会污染结果。因此：
- 若存在一个独立有效的分支，融合**应当**保得住它，而不是平均稀释；
- 实测两个分支在 fork 口径下都为负 → **不是被稀释，而是分支本身没带来可用信息**
  （1536 独立实测 −0.00530 直接佐证）。
- HFlip 造成 mAP75 塌陷（而非分数被平滑）也符合「择优式融合」的机制预测。

**④（本轮新增）增益的族构成脆弱性 —— 这是最直接解释「本地有增益、线上无收益」的证据。**

对既有落盘预测按来源族分层重评（**复用 `official_map.py` 原函数，未重新推理**）：

| 运行 | overall | `N` (n=216) | `shuming_*` (81) | `N_N_N` (75) | `hehe_*` (18) | `*suppl*` (10) |
|---|---:|---:|---:|---:|---:|---:|
| RGBID_baseline | 0.50924 | 0.41828 | 0.46922 | 0.45100 | 0.31945 | 0.37492 |
| HFlip Δ | **−0.00650** | **+0.00249** | +0.00523 | −0.00217 | +0.01671 | +0.00631 |
| MultiScale Δ | **+0.00216** | **−0.00456** | **+0.01809** | **+0.01585** | +0.00992 | +0.01446 |

**multiscale TTA 在族 `N` 上是负的（−0.00456），而族 `N` 占测试集 73.0%。**
它全部的正增益来自 `shuming_*` / `N_N_N` —— 这两个族在测试集里合计只占 **23.4%**（train 里是 40%）。

把 val 的族权重替换为 **test 的族权重**（同一批 val 预测，只换权重）得到重加权反事实：

| 运行 | val 权重下增益 | test 权重下增益 | 增益被侵蚀 | 净效应 |
|---|---:|---:|---:|---:|
| **MultiScale** | +0.00498 | **+0.00095** | **−0.00403** | **−0.00403** |
| HFlip | +0.00291 | +0.00210 | −0.00081 | −0.00081 |
| ens 3:1 | +0.00697 | +0.00719 | +0.00022 | +0.00022 |

（metric A 口径；metric B 方向一致：MultiScale −0.00479。分组细化后侵蚀量为 −0.0033，
量级稳健。）

**结论**：multiscale TTA 的 val 增益约 **60–75% 会被 val→test 的族构成差异吃掉**，
剩下 +0.001，完全落在噪声带内（本项目既有结论：fork 口径仅在 |Δ| > 0.008–0.015 时有信息）。
**这正是「本地测到一点、线上没有」的机制性解释**，且与 §5.3① ② 相互独立。

### 5.4 附加发现：TTA 的两个分支在可观测的 LR 子群上同样为负

按「族 × 分辨率」分层（`tta_by_group.py`），族 N 拆成 HR/LR：

| 运行 | overall | `N_HR` (189) | `N_LR` (27) | `shuming_*` (81) | `N_N_N` (75) |

## 6. 新增结构发现：test 与 train 存在帧级内容重叠

§1.1 的 stem 交集为 0，因此不存在「同名复用」。但用 **64×64 零均值归一化余弦**做内容相似度后发现重叠：

| 统计 | 值 |
|---|---|
| test(+pre) 中与 train/val 有 **cos > 0.999** 近邻的比例 | **8.0%** |
| … **> 0.99** | **14.5%** |
| … **> 0.95** | 19.9% |
| 其中 **\|Δ帧号\| ≤ 3** 的占比（>0.99 组，n=290） | **55.5%**（≤1 帧：35.2%；≤10 帧：79.7%） |
| 这些配对中属于族 `N` 的比例 | **96.2%**（279 / 290） |
| train_raw 内部自近重复（>0.99） | 7.9% |
| split_val 内部自近重复（>0.99） | 6.0%（与 train 的 374 组重叠即「同一批文件」，是方法自检） |

**按族拆分（族 N）：**

| 子群 | n | 与 train/val 有 >0.99 近邻的比例 |
|---|---:|---:|
| **族 N · LR (640×360)** | 117 | **96.6%** |
| 族 N · HR (1920×1080) | 613 | **0.3%** |
| `N_N_N` | 373 | 0.5% |
| `shuming_*` | 200 | 4.0% |
| `hehe_*` | 41 | 2.4% |
| `*suppl*` | 36 | 0.0% |

**逐对复核（256×256 灰度相关 + 平均绝对差）**：

| 配对 | r(256×256) | MAD |
|---|---:|---:|
| `test/00000037` ↔ `train/00000036` | **0.9996** | 3.28 / 255 (1.3%) |
| `test/00000071` ↔ `train/00000072` | 0.9989 | 4.05 |
| `test/00000085` ↔ `train/00000084` | 0.9991 | 3.47 |
| `test/00000010` ↔ `train/00000036` | 0.9974 | 8.39 |

**结论**：训练/测试划分**切在视频序列内部**——相邻帧分落两侧。
**LR 子集（占 test 11.7%）几乎完全被训练集覆盖（96.6%）**；HR 子集基本独立（0.3%）。

**含义（三条）**：
1. 测试集的**有效独立样本量显著低于 1000**，且偏低的那部分正是 LR 子集。
2. 「LR 与 train 不同分布」这一可观测差异，其载体图恰恰是模型见过近邻的那些图。
3. 任何**针对 LR 子集**的 TTA 调参，本质是在模型已近似记住的内容上调参 ——
   本地增益的迁移性会进一步打折。

## 8. 最终回答

### 5. 是否值得做部分 TTA？

```text
NO —— 不值得。
```

四条独立理由（任一条成立即足够否决，此处四条同时成立）：

1. **没有可作用的分布偏移。** 在任一分辨率分层内部，test 与 train 的 RGB/IR/Depth 分布
   逐项吻合（大样本分层 |d| ≤ 0.077 / 0.118 / 0.258，分别为 visible/depth/IR，
   且 IR 的最大的两三项均与对比度、动态范围无关）；小样本分层（LR，n=117）
   的差异多重比较后不显著。
2. **唯一零成本、通常安全的 TTA 家族（padding/aspect）在本数据集上构造性为零。**
   13 200 张图全部 16:9、画布恒 1280×736。没有可校正对象。
3. **真实差异是「构成偏移」，TTA 在原理上无法处理。** TTA 是逐图变换，
   不能改变「测试集里 LR 或族 N 占多少」。而唯一可观测的构成代理（分辨率）
   其 TTA 响应实测为**负**。
4. **既有 TTA 的正增益被证明集中在测试集占比最小的族上，且被 val→test 的构成差异侵蚀 60–75%。**
   加上 14.5% 的测试图与 train 存在帧级近重复（LR 子集 96.6%），
   本地「针对性调参」的测量本身就不独立。

### 6. 推荐的单变量实验数

```text
0 个
```

按你设定的门槛（「只允许提出有数据依据的部分 TTA」「Tier A 才值得做」），
**Tier A 为空，因此推荐 0 个**。

**若你仍决定花一次线上额度验证**，则唯一有最低限度推理支撑的是 **B1**，
且必须按单变量、限定 HR 子集、以官方口径 + fork 口径双读数执行。
但它**不满足本轮设定的 Tier A 门槛**，我不将其列为推荐。

### 本轮遗留的不确定性（供你裁决）

1. **「完整 TTA 线上无收益」在本仓库无记录。** §5.1。若你手上有那次线上分数，
   请提供，我可以把它纳入 §5.3 的机制对照（特别是它与 §5.3④ 的构成侵蚀量是否量级一致）。
2. **`split_val` 的族构成（shuming 20.25%）与 test（5.4%）差异巨大**，也与 train（18.5%）接近。
   这意味着**一切在 split_val 上选出的阈值/结构/TTA 决策都带构成偏差**——
   这不止影响本轮 TTA，也影响历史上所有以 split_val 为判据的结论。
   建议后续把 split_val 评估**同时报告按族分层的数字**（脚本已就绪：`tta_by_family.py`）。
3. **帧级近重复（§6）** 说明 test 与 train 不是独立采样。
   这会影响所有基于 val 的显著性判断的有效样本量估计。
