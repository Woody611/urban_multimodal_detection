# F1 后续实验建议（基于误差/数据诊断的排序）

> 基线：F1 = YOLO11m RGBD 中期融合，imgsz=1024，batch=8，SGD lr0=0.005，best mAP@0.5:0.95 = **0.51955**（ep287）。
> 目标：0.51955 → ~0.55。本报告结论全部来自 `f1_error_analysis.md` / `f1_class_metrics.csv` / `f1_data_alignment_audit.json`
> 的实测数据，不凭主观猜测。所有实验**从零训练、独立目录、不覆盖 F1/F2/F3a**，仅改单变量。

---

## 0. 当前主要瓶颈（一句话）

**小目标召回不足 + person 类主导**：整体 `P=0.867 / R=0.679`（漏检是主矛盾），
sign/bicycle/ball/person 的小目标漏检率 35~51%；person 占全部 GT 的 37.2% 却只有 AP 0.464。
根因是 8× 下采样后 <32px 目标在 P3 特征图上只剩 ~4px，信息不足。

**证据链**（决定排序）：
- **混淆矩阵：跨类误判仅 20 例 / 2847 GT = 0.70%**，漏检(734) + 误检(490) 全部是「前景 vs 背景」。
  → **排除**一切以「提高类间判别力」为假设的方向（分类头改造、跨模态注意力、类间 margin loss、难例挖掘重加权）。
- **困难类是硬漏检**：conf=0.001 + IoU=0.45（极宽松）下 sign 检测率 60.0%、bicycle 56.0%、ball 52.6%——根本没框出来，
  不是置信度被阈值砍掉。→ 增益只能来自**让网络定位到更多小目标**（分辨率 / 特征尺度 / 容量）。
- 分辨率敏感：768→1024 的 mAP +0.020（E6→E7）——小目标从更多像素中直接受益。
- 容量敏感：s→m 的 mAP +0.024（E2→E4）——模型还有吸收能力。
- 定位 gap 集中在小目标：ball AP50→AP75 掉 0.337、person 掉 0.304、sign 掉 0.237，大目标 gap 小（seat 0.056）。
- 已证伪（不再尝试）：P2 头（E5 与 E4 持平 0.478）、close_mosaic=0（E7m0）、lr0 继续下调（F3a 证伪）。

## 2. 前三个实验（详细）

### 实验 1：imgsz=1280（最高优先级，直接命中第一瓶颈）

- **为什么排第一**：第一瓶颈是小目标召回，而分辨率是唯一被历史数据验证过、且直接作用于小目标信息量的杠杆（768→1024 = +0.020）。1024 下 sign 中位面积 1363px²、ball 898px²、person 2357px²；升到 1280 后同一边长目标像素面积 ×1.56，P3 上残存像素从 ~4px 升到 ~5px，边际增益最大。
- **改变**：`imgsz: 1024 → 1280`（train/val 均 1280）；batch 若 OOM 降 8→4（SGD 下需同步把 lr0 微调或保持，见下）。
- **不改变**：模型结构、RGBD 中期融合、Depth 处理、增强、损失、SGD/lr 策略、conf/NMS/IoU/max_det/max_boxes、数据划分。
- **成功判据**：best mAP50-95 ≥ 0.530（+0.010），且 **sign/bicycle/ball 的 AP50-95 各 +0.02 以上、person +0.01 以上**（这些是直接受益类别）；训练曲线连续稳定（非孤峰）。
- **不提升怎么办**：若 best 与 F1 持平（<+0.005），说明小目标信息在 640×360 原始采集时已不可逆丢失（149 张低分辨率图 + 远距目标），则**停掉分辨率线**，转向实验 2/3（容量与模态质量）。

### 实验 2：YOLO11l RGBD（容量，第二证据）

- **为什么排第二**：容量敏感（s→m +0.024），而当前 m（~20M）在 2000 图上尚未过拟合到发散（F1 ep287 仍小幅爬升）。l（~25M）给 P3/P4 更多小目标表征通道。
- **改变**：仅模型尺度 m→l（复制 `yolo11m_midfusion_rgbd_concat_res.yaml` → 文件名含 `l`，**必须由文件名正则驱动 scale**，参照 [[model-scale-gotcha]]）。
- **不改变**：融合结构（仍是 RGBD 双分支中期融合）、数据、增强、损失、imgsz=1024、lr0=0.005。
- **成功判据**：best ≥ 0.528（+0.008），且 person/animal 等大样本类 AP 提升、small 类不倒退；训练曲线无晚期发散。
- **不提升怎么办**：若 best 与 F1 持平但 val 提前分叉/晚期下降 → **过拟合**，回退 m，并把实验 4（更长训练）降级，改为加 `erasing` 或 `close_mosaic` 后再试 l。若 l 明显更差，说明数据规模撑不起 l，容量线到此为止。

### 实验 3：RGBD + 有效深度掩码（5ch）（模态质量，针对性修复）

- **为什么排第三**：depth 通道 **31.5% 像素无有效信号**（16-bit `<300mm` 与 8-bit `==0` 都被压成 0），当前模型无法区分「有效深度=0（极近）」与「无效=0（天空/远背景）」，等于是把 1/3 的通道当成可用的 0 值噪声。加 1 通道二值掩码（有效=1）让模型显式知道哪些深度可信，是对症下药的模态修复，改动局部。
- **改变**：depth 由 1ch → 2ch（depth + valid_mask），输入 4ch→5ch；`channels: 5`；`_merge_channels` 额外拼接 `(depth>=300).astype(uint8)`（16-bit）或 `(depth>0)`（8-bit）。作为**新配置选项**（如 `use_simotm="RGBDM"`），不改既有 RGBD 路径。
- **不改变**：双分支中期融合整体架构、增强、损失、imgsz=1024、lr0=0.005、数据划分、Depth 归一化数值本身。
- **成功判据**：best ≥ 0.525（+0.005），且 **light（FP 56 例全为背景误检，是纯模态质量受害类）/boat/animal（依赖深度语义的类）AP 提升**；训练稳定。
- **不提升怎么办**：若持平，说明模型已自行学会忽略无效深度（31.5% 噪声未造成实质损失），则放弃掩码线，回到纯分辨率/容量线。注意此实验需改代码，先做**单 epoch 冒烟**确认 5ch 数据通路与增强分支正确（参照 plan 里的 5ch 验证），再全量训练。

## 3. 后续备选（按需触发）

- **实验 4（450 epoch）**：F1 在 ep287 仍缓慢爬升、E7 在 ep257 后进入平台期+分叉。若实验 1/2 的曲线显示「还没收敛」，延长到 450 epoch 是零风险的增益；若曲线已分叉则跳过。
- **实验 5（数据修复）**：84 个越界框（~3%）+ 2 张坏图（000050 含 37 GT、003817 含 3 GT）当前被 val 整体丢弃。clamp 越界框 + 不再丢弃坏图可让评估口径更干净、恢复 40 GT 参与评估。这是**口径修复**，主要让 mAP 更诚实，实际增益有限（+0.002~0.006）。
- **实验 6/7（后期/早期融合）**：改变融合架构，违背「保持 RGBD 双分支中期融合」约束且风险高，仅在实验 1~5 全部打满仍差口气时，作为最后的结构性尝试；当前**不做**。
- **实验 8（P2 / 跨模态注意力）**：P2 已证伪（E5）。跨模态注意力 / 分类头改造类方案针对的是「类间判别」，
  而混淆矩阵显示跨类误判仅 0.70%——**前提不成立**，**不排入计划**。

---

## 4. 组合路线（建议执行顺序）

```
阶段A（并行）: 实验1(1280) + 实验2(YOLO11l)   → 取较优者作为新基线 B
阶段B（若 A 有效）: 在 B 上叠加 实验3(掩码) + 实验4(450ep)
阶段C（收尾）: 实验5(数据修复) 统一口径后提交 best
```

预期：A 阶段 +0.010~0.020，B 阶段 +0.005~0.015，合计约 **+0.015~+0.035**，可把 0.51955 推近 0.54~0.55。若 A 阶段无增益，则瓶颈在原始数据采集（小目标信息已丢），届时如实上报「数据侧天花板」，而非继续空转实验。
