## 2. Matching Method

- GT / 预测：与 `official_map.py` 同一份数据（398 张有效 val 图，GT 2807，预测 4824）。
- **官方 TP@t**：`official_map.curve_for_class` 的 conf 顺序贪心匹配（逐类、逐 IoU 阈值独立）。
- **每 GT 的最佳匹配**：
  - `best_iou_cls` = 同类预测中的最大 IoU（用于分组与回归分解）
  - `bi_any` / `pc_any` = 任意类的最大 IoU 及其类别（用于类别正确性）
  - `conf_cls` = 上述同类最佳框的置信度
- COCO 面积：native 像素，small<1024 / medium 1024–9216 / large>9216（与既有 audit 一致）。
- 越界标签整图作废（与 `official_map` 一致，剔除 2 张）。

## 11. Root-cause Evidence

### 1 `SMALL_SCALE_INFORMATION_LIMIT` —— 证据

**支持**：
- **20.8% 的 small GT**：最佳同类框 IoU==0，且其尺寸是 GT 的 **2.98×/3.55×（中位）**，
  74.0% 的匹配框 rw>1.5 → **模型没有产出尺寸合适的小框**。
- **6.5% 完全没有同类预测**。
- TP@0.5 随 √area 单调上升（30.8% → 69.8%），无悬崖但持续恶化。
- 组 A/B 的类别正确率 ≥97%，而组 C（IoU<0.5）仅 55.1% → 失败的框**连类都不对**，
  符合"那个位置没有真正的检测"而非"框画歪了"。

**反证**：
- **uav 反例**：small uav TP@0.5 = **100%**、TP@0.75 = 83.3%（n=18） →
  证明"小"本身不是绝对障碍，**背景对比度**也是变量。
- `C2PSA`（P5 上的 HW×HW 注意力）已存在，说明模型并非完全没有跨尺度建模能力。

**量级**：直接可归因 **27.3%**（20.8% + 6.5%）的 small GT 完全没有可用检测；
这是六类中**最大**的一块。

### 2 `BOX_LOCALIZATION`（随机抖动）—— 证据

**支持**：
- 组分 B：**30.7%** 的 small GT 落在 0.50–0.75，中位 IoU 0.61，dx/dy 中位 ±0.02。
- matched small 的 **|dx| 中位 0.0495 vs large 0.0169（2.9×）**，P90 0.1480 vs 0.0884。
- **偏置极小（−1.2%/+1.2%）而抖动很大** → 不可用固定系数修正。

**反证**：这 30.7% 的类别正确率 97.4%，说明"找到并认对了，只是框不精"。

**量级**：**30.7%** 的 small GT 处于该区间。

### 3 `CONFIDENCE_CLASSIFICATION` —— 证据

**支持**：small 类别正确率 **80.1%**（vs medium 89.9% / large 95.7%）；
在 **IoU==0 组中仅 45.5%**；**bicycle 41.7% / light 27.3% / seat 44.4%** 三个类的类别正确率极低。

**反证（重要）**：§6 显示 small 的 **conf 与 IoU 正相关**，不存在"高 conf 但低 IoU"的分群
→ **不是"自信地定位错"**；且类别正确率只在**已经失败的** GT 上才低。

**量级**：**中等**；主要作为 `SMALL_SCALE_INFORMATION_LIMIT` 的伴随现象。

### 4 `BOX_SCALE_REGRESSION` —— 证据

**支持**：small rw/rh 均值 **1.0337/1.0455**，**统计显著**（|均值−1| > 2SE，SE=0.0135/0.0112）；
medium/large 全部**不显著**。

**反证**：偏置仅 **+3.4%/+4.6%**，而尺度分布 P10–P90 = 0.80–1.28（**±24%**）→ 偏置比分布宽度小 ~6×。
用固定系数修正最多消除 4%，而 medium/large 无偏说明这不是全局尺度先验问题。

**量级**：**小**。

### 5 `CROWDED_OBJECT_INTERFERENCE` —— 证据

**支持**：描述性事实 —— small GT 的最近邻中位距离 = 自身 √area 的 **1.34 倍**；
17.0% 的 small GT 有另一 GT 中心落在其内部；原始分组 isolated 69.3% vs dense 57.1%。

**反证（决定性）**：**控制 √area 后关联消失甚至反向** —— [16,22) 档 dense 62.6% > isolated 50.0%。
原因是 isolated 组目标更大（20.4 vs 16.3 px）。

**量级**：**小（尺寸混杂）**。

### 6 `NMS_SUPPRESSION` —— 证据

**支持**：无。
**反证**：iou 0.5/0.6/0.8 对 ΔSmall = **+0.00009 / +0.00005 / −0.00012**；
iou=0.8 多保留 733 个框后 small AP 反降；`max_det` 从未触顶（最大 177）。

**量级**：**≈ 0**。

## 13. Conclusion

```text
ERROR_ATTRIBUTION_COMPLETE
```

**small-object mAP50-95 低的主因分解（按量化贡献排序）**：

1. **`SMALL_SCALE_INFORMATION_LIMIT`（最大）** —— 27.3% 的 small GT 完全没有尺寸合适的同类框
   （20.8% 匹配到约 3× 大的框 + 6.5% 无同类预测）。**模型在这些位置不生成小尺度框。**
2. **`BOX_LOCALIZATION` 随机抖动（第二）** —— 30.7% 找到但 IoU 0.5–0.75；
   small 的中心相对抖动是 large 的 2.9×。
3. `CONFIDENCE_CLASSIFICATION`（中）—— small 类别正确率 80.1%，且集中在已失败的 GT 上；**不是 Case A**。
4. `BOX_SCALE_REGRESSION`（小）—— 显著但仅 +3.4%/+4.6%。
5. `CROWDED_OBJECT_INTERFERENCE`（小）—— **控制尺寸后消失**。
6. `NMS_SUPPRESSION`（≈0）—— **实测为零**；max_det 从未触顶。

**「不是瓶颈」的明确排除**（§12）：
- **NMS / max_det**（实测 ΔSmall ≤ 0.00012；max_det 从未生效）
- **crowded scenes**（尺寸控制后无效应）
- **系统性的、可用固定系数修正的 box 尺度/中心偏置**（存在但比抖动小一个数量级）
- **分类头能力不足**（组 A/B 类别正确率 ≥97%；且 conf 与 IoU 正相关，非"自信地定位错"）

**当前正式模型是否仍应作为最终保底**：

> **是。** 本次审计**没有发现任何可归因于"后处理 / NMS / 推理参数"的可修复项**，
> 也**没有发现可被固定系数修正的系统偏置**。误差来源位于**模型的小尺度框生成能力**，
> 而该方向的三个候选（1536 训练、P2 层、P3 通道注意力）在本项目**均已实测为中性或负**。
> **正式保底维持：RGBID Early Fusion，official 0.50928 / online 0.53180。**

## 15. ⚠️ 必须报备：本次审计中发现并修复的一处项目级回归

**背景**：上一轮 P3 Identity Attention 准备阶段，我在 `ultralytics/nn/modules/block.py` 的
`C3k2.forward` 中写成 `return self.attn(x) if self.attn is not None else x`。

**缺陷**：`attn` 是**构造函数新增的属性**，而**旧 checkpoint 里 pickle 的 `C3k2` 对象没有它**。
加载旧 checkpoint → 对象缺少 `attn` → `forward` 抛 `AttributeError`。

**影响范围（实测）**：**所有既有 checkpoint 的前向推理全部崩溃** ——
包括正式 `best.pt`、F4、以及 `runs/*/weights/best.pt` 全部 30 个。
（本轮 §9 的 NMS 变体最初 3 次运行 `exit=1 / txt=0` 就是这个原因。）

**已修复**：改为
```python
x = super().forward(x)
attn = getattr(self, "attn", None)
return attn(x) if attn is not None else x
```

**修复后验证**：
```
正式 best.pt（旧 checkpoint，无 attn 属性）  -> 载入 OK，forward OK
P3Attn probe（含 attn）                      -> 载入 OK，forward OK
历史 checkpoint 抽检                          -> OK = 30 / FAIL = 0（共 30 个）
identity 行为未变                            -> layer16 输出 max|Δ| = 0.000e+00
```

**未受影响的历史结论**：正式 0.50928、1536 两个探针、P3Attn probe 官方 0.50251
都是在**该缺陷存在之前或通过含 `attn` 的 checkpoint** 产生的，**结论均有效**。
但**该缺陷期间无法对任何旧 checkpoint 做重新推理** —— 这正是它对本轮审计的直接影响。

**教训（供后续参考）**：给既有模块类新增属性时，**必须用 `getattr` 访问**，
否则会静默破坏全部历史 checkpoint 的推理链路。
