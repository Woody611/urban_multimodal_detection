# 模型设计说明文档

## 1. 任务概述

本项目为 Urban‑MultiModal‑Object‑Detection 城市场景多模态目标检测任务。
项目输入为空间已经对齐的 RGB、红外(Infrared)、深度(Depth)三种图像；输出图像中目标物体的检测框以及对应类别。
检测一共包含12个城市场景目标类别。

## 2. Baseline模型

Baseline 采用 RGB 单模态图像作为输入。
数据流：

1. 将RGB图像送入骨干网络进行图像特征提取，得到多尺度特征图；
2. 提取后的特征送入检测头模块；
3. 检测头完成候选框预测、类别分类，输出目标检测结果。
   各模块作用：
- 骨干网络：负责从原始RGB图像提取不同尺度的视觉特征；
- 检测头：基于提取到的特征，预测目标边界框与物体类别。
  Baseline 的作用是建立单模态参照基准，用来对比后续多模态融合模型的效果。
  
  ## 3. 多模态融合模型
  
  多模态模型同时接收 RGB、Infrared、Depth 三种对齐后的图像：
1. 三个模态分别通过各自的特征提取分支，独立提取对应模态的图像特征；
2. 在指定特征层对多模态特征执行融合操作；
3. 将融合完成的综合特征送入检测头；
4. 检测头完成边界框回归与类别分类，输出最终检测结果。
   
   > 融合方案严格参考 configs/model.yaml 配置，不额外增加未确定的模型结构。
   
   ## 4. 输入与输出
   
   ### 输入
- RGB：可见光彩色图像
- Infrared：红外图像
- Depth：深度图像
  三张图像已经完成空间对齐，可以直接送入模型。
  
  ### 输出
- 各个目标的边界框坐标
- 目标所属类别（共12类）
  
  ## 5. 模型设计思路
1. 首先搭建 RGB 单模态 Baseline 模型，验证整套训练、推理流程可以正常跑通，拿到单模态的性能基准；
2. 在Baseline的基础上接入红外、深度两个模态，做多模态特征融合；
3. 对比单模态与多模态的检测效果，验证多模态信息对城市场景检测是否带来增益。
   
   ## 6. 后续优化
   
   后续将根据实际实验结果进行模型的调整与优化，暂不预设具体优化方向与实验效果。
